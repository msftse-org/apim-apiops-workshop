# Workshop presentation

The Microsoft-themed PowerPoint includes the workshop URL, module map, runnable command sequences and validation boundaries. [Download the 20-slide PowerPoint](APIM-APIOps-Customer-Workshop.pptx).

Slides 1–14 explain APIM configuration as code, the supported command families and the measured demo. Slides 15–20 introduce the public workshop, its 12 labs and the native commands customers run in their own Azure environment. Speaker notes link to the detailed lab steps, upstream documentation and validation boundaries.

The visual template retains the Microsoft Ignite dark theme, sourced from the [community-distributed template](https://github.com/olohmann/dark-theme-pptx/blob/main/assets/template.pptx).
